# Hướng dẫn sử dụng VcamPlus

## File nhận được

- File `.deb` để cài trên iPhone jailbreak.
- File relay `.zip` để chạy trên Windows.

## Cài trên iPhone

1. Mở Sileo.
2. Cài file `.deb`.
3. Respring nếu được yêu cầu.
4. Mở menu Vcam.
5. Đăng nhập tài khoản được cấp.

## Chạy trên Windows

1. Giải nén relay vào:

```text
C:\VcamPlusRelay
```

2. Chạy:

```text
relay.exe
```

3. Đăng nhập cùng tài khoản với iPhone.

## OBS

Server URL:

```text
rtmp://<IP-Windows>/live
```

Stream Key: để trống.

## Nếu iPhone không thấy RTMP

1. Đảm bảo iPhone và Windows cùng Wi-Fi.
2. Mở relay trước.
3. Hide/mở lại menu Vcam.
4. Kiểm tra Windows firewall port `1935`.
