# iPhone Install Guide

## Yêu cầu

- iPhone jailbreak.
- Sileo hoặc package manager tương đương.
- DEB đúng bản khách.
- iPhone và Windows cùng Wi-Fi/LAN.

## Cài đặt

1. Gửi DEB vào iPhone.
2. Mở bằng Sileo.
3. Cài đặt.
4. Respring.
5. Mở menu Vcam.
6. Login.

## Nếu respring/safemode

1. Gỡ DEB vừa cài.
2. Cài lại bản known-good.
3. Báo lại thiết bị/iOS/jailbreak.
4. Không cài tiếp bản khác trước khi có hướng dẫn.
